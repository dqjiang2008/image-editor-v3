# 道具基础形象生成 · 手绘素描

---

## 一、基础原则

1. **道具为本** — 造型由道具描述决定
2. **风格一致** — 手绘素描，铅笔笔触
3. **多角度展示** — 至少3个角度
4. **黑白灰调** — 线条粗细变化，纸张纹理

---

## 二、提示词模板

```
{道具名称}，手绘素描风格，铅笔笔触，线条粗细变化，纸张纹理，
{道具描述}，黑白灰调，铅笔线条细腻，
多角度展示：正面+侧面+45度角，
均匀柔光，浅灰背景或素描纸纹理，
道具造型清晰，明暗层次丰富
图中不要有任何文字
```

---

## 三、约束规则

### 必守
| 编号 | 规则 |
|---|---|
| R1 | 必须为手绘素描风格 |
| R2 | 必须声明「铅笔笔触 + 线条粗细变化」 |
| R3 | 多角度展示必须完整 |

### 严禁
| 编号 | 严禁 |
|---|---|
| X1 | 3D渲染/写实摄影 |
| X2 | 高饱和彩色 |
| X3 | 复杂背景 |
