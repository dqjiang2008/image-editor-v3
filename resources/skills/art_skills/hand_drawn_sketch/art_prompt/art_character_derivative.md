# 人物服化衍生 · 手绘素描

---

## 一、基础原则

1. **角色为本** — 所有服化衍生必须基于角色基础形象
2. **风格一致** — 必须保持手绘素描风格
3. **场景适配** — 服装/妆容/发型需适配当前场景需求
4. **黑白灰调** — 铅笔笔触，线条粗细变化

---

## 二、衍生类型

### 正式礼服

| 项目 | 约束 |
|---|---|
| 风格 | 与基础形象一致，手绘素描 |
| 色彩 | 黑白灰为主，明暗层次 |
| 细节 | 铅笔线条精细，阴影自然 |

### 战斗/武服

| 项目 | 约束 |
|---|---|
| 风格 | 轻便实用，素描质感 |
| 色彩 | 深色系为主，明暗对比强 |
| 细节 | 铅笔线条有力，轮廓清晰 |

### 日常/休闲

| 项目 | 约束 |
|---|---|
| 风格 | 简约舒适，素描清新 |
| 色彩 | 浅灰系，柔和过渡 |
| 细节 | 铅笔线条轻松，边缘柔和 |

## 四、约束规则

### 必守
| 编号 | 规则 |
|---|---|
| R1 | 必须保持手绘素描风格 |
| R2 | 必须基于角色基础形象 |
| R3 | 色彩必须以黑白灰为主 |

### 严禁
| 编号 | 严禁 |
|---|---|
| X1 | 3D渲染/写实摄影/数字绘画光滑感 |
| X2 | 高饱和彩色/荧光色 |
| X3 | 与角色基础形象严重不符 |
