# 分镜帧/视频生成 · 手绘素描

---

## 一、基础原则

1. **分镜为本** — 画面由分镜描述决定
2. **风格一致** — 手绘素描，铅笔笔触
3. **叙事连贯** — 帧与帧之间风格一致

---

## 二、提示词模板

```
{分镜描述}，手绘素描风格，铅笔笔触，线条粗细变化，纸张纹理，
{角色描述}，{场景描述}，
{镜头角度}，{景别}，
黑白灰调，铅笔线条细腻，均匀柔光，
素描动画风格，明暗层次丰富
图中不要有任何文字
```

---

## 三、视频风格标签

```
hand-drawn sketch animation, pencil strokes, line weight variation, paper texture visible, grayscale tones, charcoal shading, traditional drawing feel, cross-hatching shadows
```

---

## 四、约束规则

### 必守
| 编号 | 规则 |
|---|---|
| R1 | 必须保持手绘素描风格 |
| R2 | 必须声明「铅笔笔触 + 线条粗细变化」 |
| R3 | 帧与帧之间风格必须一致 |

### 严禁
| 编号 | 严禁 |
|---|---|
| X1 | 3D渲染/写实摄影 |
| X2 | 高饱和彩色 |
| X3 | 数字绘画光滑感 |
