# 场景基础形象生成 · 手绘素描

---

## 一、基础原则

1. **场景为本** — 造型由场景描述决定
2. **风格一致** — 手绘素描，铅笔笔触
3. **氛围营造** — 黑白灰层次，明暗对比
4. **线条质感** — 线条粗细变化，纸张纹理

---

## 二、提示词模板

```
{场景名称}，手绘素描风格，铅笔笔触，线条粗细变化，纸张纹理，
{场景类型}，{室内/室外}，{季节+时间}，
{场景描述}，黑白灰调，铅笔线条细腻，
{氛围关键词}，均匀柔光，
素描风景，明暗层次丰富，阴影自然过渡
图中不要有任何文字
```

## 三、约束规则

### 必守
| 编号 | 规则 |
|---|---|
| R1 | 必须为手绘素描风格 |
| R2 | 必须声明「铅笔笔触 + 线条粗细变化 + 纸张纹理」 |
| R3 | 色彩必须以黑白灰为主 |

### 严禁
| 编号 | 严禁 |
|---|---|
| X1 | 3D渲染/写实摄影 |
| X2 | 高饱和彩色/荧光色 |
| X3 | 复杂数字元素 |
