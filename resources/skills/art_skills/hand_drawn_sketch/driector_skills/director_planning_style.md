# 叙事规划手法 · 手绘素描

---

## 一、风格定位

手绘素描风格适合以下叙事类型：
- 悬疑推理故事
- 文艺回忆录
- 黑白 noir 题材
- 心理剧情

## 二、叙事节奏

| 阶段 | 节奏 | 明暗建议 |
|---|---|---|
| 开篇 | 缓慢引入 | 浅灰调，线条轻柔 |
| 发展 | 渐入悬疑 | 明暗对比逐渐增强 |
| 高潮 | 紧张爆发 | 强烈明暗对比，阴影加深 |
| 结尾 | 余韵悠长 | 回归浅灰调，留白感 |

## 三、视觉叙事技巧

1. **明暗情绪**：用明暗变化暗示情绪变化
2. **线条力度**：用线条粗细变化暗示紧张程度
3. **留白处理**：适当留白营造呼吸感和想象空间
4. **阴影层次**：用阴影深度暗示剧情深度
