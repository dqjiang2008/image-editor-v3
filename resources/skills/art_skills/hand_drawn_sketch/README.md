# 手绘素描风格说明

本风格专为"手绘素描"题材打造，所有美术提示词、规范和生成内容均严格遵循：

- **手绘艺术**：以传统手绘素描为美学基础，强调铅笔/炭笔笔触、线条质感
- **素描质感**：保留手绘线条的粗细变化、阴影层次、纸张纹理
- **黑白灰调**：以黑白灰为主色调，适合悬疑、 noir、文艺等题材
- **艺术表现力**：画面具有手工绘画的温度感，区别于数字绘画的冰冷感

## 适用范围

- 手绘风格的AI美术生成（角色、场景、道具、分镜等）
- 需要素描质感、黑白灰调的视觉创作
- 悬疑、文艺、回忆题材的动画短片

## 严禁内容

- 3D渲染、写实摄影风格
- 高饱和彩色（本风格以黑白灰为主）
- 数字绘画的光滑平整感
- 暗示性、暴露等不适宜内容

## 风格体验

在本风格下，您将体验到：

- 角色形象以素描线条勾勒，具有手绘特有的笔触质感
- 场景以黑白灰层次表现，阴影过渡自然
- 道具造型简洁有力，线条清晰
- 分镜与视频均以手绘素描为基础，强调线条艺术与明暗对比

---

本风格仅适用于"手绘素描"相关项目。如需其他风格（如写实、3D、水彩等），请勿使用本套提示词。
