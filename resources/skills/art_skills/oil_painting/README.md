# 油画绘画风格说明

本风格专为"油画绘画"题材打造，所有美术提示词、规范和生成内容均严格遵循：

- **油画艺术**：以传统油画为美学基础，强调厚重笔触、色彩层次、画布纹理
- **古典美学**：保留油画的质感与深度，适合史诗、古典、艺术题材
- **色彩浓郁**：色彩饱和度高但不荧光，具有油画的厚重感与光泽
- **艺术表现力**：画面具有手工绘画的温度感，区别于数字绘画的冰冷感

## 适用范围

- 油画风格的AI美术生成（角色、场景、道具、分镜等）
- 需要油画质感的视觉创作
- 史诗、古典、艺术题材的动画短片

## 严禁内容

- 3D渲染、写实摄影风格
- 数字绘画的光滑平整感
- 现代元素混入古典题材
- 暗示性、暴露等不适宜内容

## 风格体验

在本风格下，您将体验到：

- 角色形象以油画笔触勾勒，色彩厚重有层次
- 场景具有油画特有的质感与深度，画布纹理可见
- 道具造型古典优雅，色彩浓郁
- 分镜与视频均以油画艺术为基础，强调古典美学

---

本风格仅适用于"油画绘画"相关项目。如需其他风格（如写实、3D、像素等），请勿使用本套提示词。
