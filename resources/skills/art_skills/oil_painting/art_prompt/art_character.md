# 人物基础形象生成 · 油画风格

---

## 一、基础形象原则

1. **面容即灵魂** — 五官是角色唯一锚点，油画笔触精细渲染
2. **角色为本** — 基础着装由角色描述决定
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **古典浓郁** — 油画笔触，色彩层次，画布纹理

---

## 六、基础服装约束

> 基础服装由角色描述决定其最自然的常规着装。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 古典/史诗 | 古典长裙/长袍（浓郁色彩） |
| 奇幻/冒险 | 斗篷/武服（油画质感） |
| 日常/文艺 | 简约常服（古典色系） |
| 角色描述未明确 | 简约常服（按性别匹配） |

### 着装统一规则

- 服装风格须与油画绘画美学一致（厚重笔触、色彩层次）
- 颜色浓郁厚重，无现代元素
- 四视图服装款式完全一致

## 七、四视图设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 景别 | 要求 |
|---|---|---|---|---|
| 左一 | 人像特写 | 正面平视 | 头顶至锁骨 | 面部占60%+，五官清晰 |
| 左二 | 正视图 | 正面 0° | 全身立像 | 从头到脚完整展示 |
| 右二 | 侧视图 | 右侧 90° | 全身立像 | 纯侧面轮廓清晰 |
| 右一 | 后视图 | 后方 180° | 全身立像 | 后脑/背部清晰 |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面从左至右并排四视图 |
| 背景 | 纯净中性色或画布纹理 |
| 站姿 | 自然站立、双脚平行微分 |
| 全身展示 | 必须从头顶到脚底完整入画 |
| 特写展示 | 必须从头顶到锁骨完整入画 |
| 表情 | 中性微表情，符合角色气质 |
| 光线 | 古典光照，明暗层次分明 |
| 一致性 | 四视图的肤色/体型/发型/面容/基础服装完全一致 |
| 画面比例 | 建议 4:1 或 3:1 |

## 九、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为油画绘画风格 |
| R2 | 必须声明「油画笔触 + 色彩层次 + 画布纹理」 |
| R3 | 色彩必须体现「厚重浓郁」效果 |
| R4 | 必须指定「四视图一致性」 |
| R5 | 全身立像必须从头顶到脚底完整展示 |
| R6 | 必须声明角色身高和头身比 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 3D渲染/写实摄影/数字绘画光滑感 |
| X2 | 高饱和荧光色/霓虹色 |
| X3 | 复杂场景背景（必须纯色或画布纹理） |
| X4 | 全身立像裁切头顶或脚底 |
| X5 | 忽略身高和头身比约束 |
