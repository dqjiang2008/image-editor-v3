# 道具基础形象生成 · 油画风格

---

## 一、基础原则

1. **道具为本** — 造型由道具描述决定
2. **风格一致** — 油画绘画，厚重笔触
3. **多角度展示** — 至少3个角度
4. **色彩浓郁** — 色彩层次，画布纹理

---

## 二、提示词模板

```
{道具名称}，油画绘画风格，厚重笔触，色彩层次，画布纹理，古典光泽感，
{道具描述}，浓郁色彩，油画笔触细腻，
多角度展示：正面+侧面+45度角，
古典光照，中性色背景或画布纹理，
道具造型清晰，色彩层次丰富
图中不要有任何文字
```

---

## 三、约束规则

### 必守
| 编号 | 规则 |
|---|---|
| R1 | 必须为油画绘画风格 |
| R2 | 必须声明「油画笔触 + 色彩层次」 |
| R3 | 多角度展示必须完整 |

### 严禁
| 编号 | 严禁 |
|---|---|
| X1 | 3D渲染/写实摄影 |
| X2 | 高饱和荧光色 |
| X3 | 复杂背景 |
