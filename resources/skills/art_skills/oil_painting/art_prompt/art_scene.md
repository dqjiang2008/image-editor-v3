# 场景基础形象生成 · 油画风格

---

## 一、基础原则

1. **场景为本** — 造型由场景描述决定
2. **风格一致** — 油画绘画，厚重笔触
3. **氛围营造** — 色彩层次丰富，古典光泽
4. **画布质感** — 画布纹理可见，笔触清晰

---

## 二、提示词模板

```
{场景名称}，油画绘画风格，厚重笔触，色彩层次，画布纹理，古典光泽感，
{场景类型}，{室内/室外}，{季节+时间}，
{场景描述}，浓郁色彩，油画笔触细腻，
{氛围关键词}，古典光照，
油画风景，色彩层次丰富，笔触厚重有质感
图中不要有任何文字
```

## 三、约束规则

### 必守
| 编号 | 规则 |
|---|---|
| R1 | 必须为油画绘画风格 |
| R2 | 必须声明「油画笔触 + 色彩层次 + 画布纹理」 |
| R3 | 色彩必须体现厚重浓郁效果 |

### 严禁
| 编号 | 严禁 |
|---|---|
| X1 | 3D渲染/写实摄影 |
| X2 | 高饱和荧光色/霓虹色 |
| X3 | 复杂数字元素 |
