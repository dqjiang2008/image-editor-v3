# 人物基础形象生成 · 像素艺术

---

## 一、基础形象原则

1. **面容即灵魂** — 五官是角色唯一锚点，像素色块精细排列
2. **角色为本** — 基础着装由角色描述决定
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **像素美学** — 像素网格，色块分明，有限调色板

---

## 二、面容约束

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，像素色块排列 |

## 六、基础服装约束

> 基础服装由角色描述决定其最自然的常规着装。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 学生/青春 | 校服/休闲装（明快色系） |
| 奇幻/冒险 | 长裙/斗篷（像素质感） |
| 日常/趣味 | 简约常服（有限调色板） |
| 角色描述未明确 | 简约常服（按性别匹配） |

### 着装统一规则

- 服装风格须与像素艺术美学一致（像素网格、色块分明）
- 颜色使用有限调色板，无复杂花纹
- 四视图服装款式完全一致

## 七、四视图设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 景别 | 要求 |
|---|---|---|---|---|
| 左一 | 人像特写 | 正面平视 | 头顶至锁骨 | 面部占60%+，五官清晰 |
| 左二 | 正视图 | 正面 0° | 全身立像 | 从头到脚完整展示 |
| 右二 | 侧视图 | 右侧 90° | 全身立像 | 纯侧面轮廓清晰 |
| 右一 | 后视图 | 后方 180° | 全身立像 | 后脑/背部清晰 |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面从左至右并排四视图 |
| 背景 | 纯净中性色或像素网格背景 |
| 站姿 | 自然站立、双脚平行微分 |
| 全身展示 | 必须从头顶到脚底完整入画 |
| 特写展示 | 必须从头顶到锁骨完整入画 |
| 表情 | 中性微表情，符合角色气质 |
| 光线 | 均匀光照，色块分明 |
| 一致性 | 四视图的肤色/体型/发型/面容/基础服装完全一致 |
| 画面比例 | 建议 4:1 或 3:1 |

## 九、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为像素艺术风格 |
| R2 | 必须声明「像素网格 + 色块分明 + 锯齿边缘」 |
| R3 | 色彩必须体现「有限调色板」效果 |
| R4 | 必须指定「四视图一致性」 |
| R5 | 全身立像必须从头顶到脚底完整展示 |
| R6 | 必须声明角色身高和头身比 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 3D渲染/写实摄影/平滑渐变/抗锯齿 |
| X2 | 高饱和荧光色/霓虹色 |
| X3 | 复杂场景背景（必须纯色或像素网格） |
| X4 | 全身立像裁切头顶或脚底 |
| X5 | 忽略身高和头身比约束 |
