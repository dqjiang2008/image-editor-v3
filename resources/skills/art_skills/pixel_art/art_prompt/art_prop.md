# 道具基础形象生成 · 像素艺术

---

## 一、基础原则

1. **道具为本** — 造型由道具描述决定
2. **风格一致** — 像素艺术，像素网格
3. **多角度展示** — 至少3个角度
4. **色块分明** — 有限调色板，锯齿边缘

---

## 二、提示词模板

```
{道具名称}，像素艺术风格，像素网格，色块分明，锯齿边缘，有限调色板，
{道具描述}，有限调色板，像素色块细腻，
多角度展示：正面+侧面+45度角，
均匀光照，中性色背景或像素网格背景，
道具造型清晰，色块层次丰富
图中不要有任何文字
```

---

## 三、约束规则

### 必守
| 编号 | 规则 |
|---|---|
| R1 | 必须为像素艺术风格 |
| R2 | 必须声明「像素网格 + 色块分明」 |
| R3 | 多角度展示必须完整 |

### 严禁
| 编号 | 严禁 |
|---|---|
| X1 | 3D渲染/写实摄影 |
| X2 | 平滑渐变/抗锯齿 |
| X3 | 复杂背景 |
