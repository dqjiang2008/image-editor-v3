# 分镜帧/视频生成 · 像素艺术

---

## 一、基础原则

1. **分镜为本** — 画面由分镜描述决定
2. **风格一致** — 像素艺术，像素网格
3. **叙事连贯** — 帧与帧之间风格一致

---

## 二、提示词模板

```
{分镜描述}，像素艺术风格，像素网格，色块分明，锯齿边缘，有限调色板，
{角色描述}，{场景描述}，
{镜头角度}，{景别}，
有限调色板，像素色块细腻，均匀光照，
像素动画风格，色块层次丰富，复古游戏感
图中不要有任何文字
```

---

## 三、视频风格标签

```
pixel art animation, pixel grid visible, distinct color blocks, jagged edges, limited color palette, 8-bit/16-bit aesthetic, retro game feel, crisp pixel rendering, no anti-aliasing
```

---

## 四、约束规则

### 必守
| 编号 | 规则 |
|---|---|
| R1 | 必须保持像素艺术风格 |
| R2 | 必须声明「像素网格 + 色块分明」 |
| R3 | 帧与帧之间风格必须一致 |

### 严禁
| 编号 | 严禁 |
|---|---|
| X1 | 3D渲染/写实摄影 |
| X2 | 平滑渐变/抗锯齿 |
| X3 | 现代高清渲染感 |
