# 场景基础形象生成 · 像素艺术

---

## 一、基础原则

1. **场景为本** — 造型由场景描述决定
2. **风格一致** — 像素艺术，像素网格
3. **氛围营造** — 色块分明，有限调色板
4. **复古游戏感** — 锯齿边缘，明快色彩

---

## 二、提示词模板

```
{场景名称}，像素艺术风格，像素网格，色块分明，锯齿边缘，有限调色板，
{场景类型}，{室内/室外}，{季节+时间}，
{场景描述}，有限调色板，像素色块细腻，
{氛围关键词}，均匀光照，
像素风景，色块层次丰富，复古游戏感
图中不要有任何文字
```

---

## 三、约束规则

### 必守
| 编号 | 规则 |
|---|---|
| R1 | 必须为像素艺术风格 |
| R2 | 必须声明「像素网格 + 色块分明 + 锯齿边缘」 |
| R3 | 色彩必须体现有限调色板效果 |

### 严禁
| 编号 | 严禁 |
|---|---|
| X1 | 3D渲染/写实摄影 |
| X2 | 平滑渐变/抗锯齿 |
| X3 | 复杂数字元素 |
