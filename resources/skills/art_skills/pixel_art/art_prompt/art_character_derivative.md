# 人物服化衍生 · 像素艺术

---

## 一、基础原则

1. **角色为本** — 所有服化衍生必须基于角色基础形象
2. **风格一致** — 必须保持像素艺术风格
3. **场景适配** — 服装/妆容/发型需适配当前场景需求
4. **像素美学** — 像素网格，色块分明

---

## 二、衍生类型

### 正式礼服

| 项目 | 约束 |
|---|---|
| 风格 | 与基础形象一致，像素艺术 |
| 色彩 | 有限调色板，色块分明 |
| 细节 | 像素色块精细，边缘锯齿 |

### 战斗/武服

| 项目 | 约束 |
|---|---|
| 风格 | 轻便实用，像素质感 |
| 色彩 | 深色系为主，色块对比强 |
| 细节 | 像素色块有力，轮廓清晰 |

### 日常/休闲

| 项目 | 约束 |
|---|---|
| 风格 | 简约舒适，像素明快 |
| 色彩 | 浅色系，色块柔和 |
| 细节 | 像素色块轻松，边缘清晰 |

## 四、约束规则

### 必守
| 编号 | 规则 |
|---|---|
| R1 | 必须保持像素艺术风格 |
| R2 | 必须基于角色基础形象 |
| R3 | 色彩必须体现有限调色板效果 |

### 严禁
| 编号 | 严禁 |
|---|---|
| X1 | 3D渲染/写实摄影/平滑渐变/抗锯齿 |
| X2 | 高饱和荧光色/霓虹色 |
| X3 | 与角色基础形象严重不符 |
