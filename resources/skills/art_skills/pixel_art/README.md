# 像素艺术风格说明

本风格专为"像素艺术"题材打造，所有美术提示词、规范和生成内容均严格遵循：

- **像素美学**：以经典像素游戏为美学基础，强调像素网格、色块分明
- **复古游戏感**：保留8-bit/16-bit时代的视觉特征，适合怀旧、独立游戏题材
- **色彩明快**：色彩鲜明但不过度饱和，适合轻松、趣味题材
- **艺术表现力**：画面具有复古游戏的温度感，区别于现代高清渲染

## 适用范围

- 像素风格的AI美术生成（角色、场景、道具、分镜等）
- 需要复古游戏感、像素美学的视觉创作
- 怀旧、独立游戏、趣味题材的动画短片

## 严禁内容

- 3D渲染、写实摄影风格
- 高清平滑的渐变效果
- 现代游戏引擎的复杂光影
- 暗示性、暴露等不适宜内容

## 风格体验

在本风格下，您将体验到：

- 角色形象以像素色块构成，具有复古游戏的视觉特征
- 场景以像素网格为基础，色彩明快，层次分明
- 道具造型简洁有力，像素感强烈
- 分镜与视频均以像素艺术为基础，强调复古游戏美学

---

本风格仅适用于"像素艺术"相关项目。如需其他风格（如写实、3D、水彩等），请勿使用本套提示词。
