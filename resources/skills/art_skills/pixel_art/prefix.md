## 二、全局色彩盘（风格基线）

> 目标：统一审美而非限制创作。像素风格以明快、有限色彩为主。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 锁定整体色调：有限调色板，色块分明，禁止平滑渐变 |
| L2 软约束 | 中 | 具体配色可自由发挥，但需保持像素感 |
| L3 例外机制 | 低 | 特殊场景可适度增加色彩数量，但仍需保持像素网格 |

### 硬约束色（默认锁定）

| 色项 | 规则 |
|---|---|
| 整体色调 | 有限调色板（16-64色），色块分明 |
| 像素处理 | 必须体现像素网格，禁止平滑/抗锯齿 |
| 边缘处理 | 必须呈现锯齿边缘，非平滑过渡 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 明快 5500-6500K（推荐） | 轻松愉快主基调 |
| 对比度 | 中高（建议保持） | 色块分明，边界清晰 |
| 饱和度 | 中高 50-80%（建议区间） | 明快但不荧光 |

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「像素艺术」风格锚定词 |
| R2 | 必须声明「像素网格 + 色块分明 + 锯齿边缘」 |
| R3 | 色彩必须体现「有限调色板」效果 |
| R4 | 边缘必须呈现「像素锯齿」效果，禁止抗锯齿 |
| R5 | 必须保留「复古游戏感」，非现代高清渲染 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「3D渲染/写实摄影/平滑渐变/抗锯齿」 |
| X2 | 严禁「高饱和荧光色/霓虹色」 |
| X3 | 严禁「现代元素混入（如智能手机、现代汽车等）」 |
| X4 | 严禁「面部变形/多指/肢体异常」倾向词 |
| X5 | 严禁「裸体/暴露/透视/暗示性描述」 |
