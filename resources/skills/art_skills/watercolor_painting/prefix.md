## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。水彩风格以透明、明快、低饱和为主。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 锁定整体色调方向：低饱和、透明感、自然色系 |
| L2 软约束 | 中 | 具体配色可自由发挥，但需保持水彩通透感 |
| L3 例外机制 | 低 | 高潮场景可适度提高色彩浓度，但仍需保持水彩质感 |

### 硬约束色（默认锁定）

| 色项 | 规则 |
|---|---|
| 整体色调 | 低饱和度（30-60%），避免荧光色/霓虹色 |
| 色彩叠加 | 必须体现透明叠色效果，非纯色填充 |
| 边缘处理 | 必须有水渍扩散/颜料流动的自然边缘 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 偏暖 4500-5500K（推荐） | 温馨治愈主基调 |
| 对比度 | 中低（建议保持） | 柔和过渡，避免强烈明暗反差 |
| 饱和度 | 中低 30-60%（建议区间） | 清新淡雅 |

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「水彩绘画」风格锚定词 |
| R2 | 必须声明「水渍边缘 + 颜料扩散 + 纸张纹理」 |
| R3 | 色彩必须体现「透明叠色」效果，非纯色填充 |
| R4 | 边缘必须呈现「水彩自然晕染」效果 |
| R5 | 必须保留「手绘笔触质感」，非数字平滑感 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「3D渲染/写实摄影/数字绘画光滑感」 |
| X2 | 严禁「高饱和荧光色/霓虹色」 |
| X3 | 严禁「现代元素混入（如手机、电脑、汽车等）」 |
| X4 | 严禁「面部变形/多指/肢体异常」倾向词 |
| X5 | 严禁「裸体/暴露/透视/暗示性描述」 |
