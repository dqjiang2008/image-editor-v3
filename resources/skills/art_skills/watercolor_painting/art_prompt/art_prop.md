# 道具基础形象生成 · 水彩风格

---

## 一、基础原则

1. **道具为本** — 造型由道具描述决定
2. **风格一致** — 水彩绘画，透明叠色
3. **多角度展示** — 至少3个角度
4. **色彩通透** — 水渍边缘，颜料扩散

---

## 二、提示词模板

```
{道具名称}，水彩绘画风格，透明叠色，水渍边缘，颜料扩散，纸张纹理，
{道具描述}，低饱和色彩，水彩笔触细腻，
多角度展示：正面+侧面+45度角，
均匀柔光，浅灰背景或水彩纸纹理，
道具造型清晰，色彩层次丰富
图中不要有任何文字
```

---

## 三、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为水彩绘画风格 |
| R2 | 必须声明「水渍边缘 + 颜料扩散」 |
| R3 | 多角度展示必须完整 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 3D渲染/写实摄影 |
| X2 | 高饱和荧光色 |
| X3 | 复杂背景 |
