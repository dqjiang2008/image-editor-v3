# 分镜帧/视频生成 · 水彩风格

---

## 一、基础原则

1. **分镜为本** — 画面由分镜描述决定
2. **风格一致** — 水彩绘画，透明叠色
3. **叙事连贯** — 帧与帧之间风格一致

---

## 二、提示词模板

```
{分镜描述}，水彩绘画风格，透明叠色，水渍边缘，颜料扩散，纸张纹理，
{角色描述}，{场景描述}，
{镜头角度}，{景别}，
低饱和色彩，水彩笔触细腻，均匀柔光，
水彩动画风格，色彩层次丰富
图中不要有任何文字
```

---

## 三、视频风格标签

```
watercolor animation style, transparent color layering, watercolor bleeding edges, paint diffusion, paper texture visible, soft pastel colors, hand-painted feel, gentle brush strokes
```

---

## 四、约束规则

### 必守
| 编号 | 规则 |
|---|---|
| R1 | 必须保持水彩风格 |
| R2 | 必须声明「透明叠色 + 水渍边缘」 |
| R3 | 帧与帧之间风格必须一致 |

### 严禁
| 编号 | 严禁 |
|---|---|
| X1 | 3D渲染/写实摄影 |
| X2 | 高饱和荧光色 |
| X3 | 数字绘画光滑感 |
