# 人物服化衍生 · 水彩风格

---

## 一、基础原则

1. **角色为本** — 所有服化衍生必须基于角色基础形象
2. **风格一致** — 必须保持水彩绘画风格
3. **场景适配** — 服装/妆容/发型需适配当前场景需求
4. **色彩通透** — 透明叠色，水渍边缘

---

## 二、衍生类型

### 正式礼服

| 项目 | 约束 |
|---|---|
| 风格 | 与基础形象一致，水彩透明叠色 |
| 色彩 | 低饱和，透明叠加 |
| 细节 | 水彩笔触精细，边缘自然晕染 |

### 战斗/武服

| 项目 | 约束 |
|---|---|
| 风格 | 轻便实用，水彩质感 |
| 色彩 | 深色系为主，透明叠色 |
| 细节 | 水彩笔触有力，边缘清晰 |

### 日常/休闲

| 项目 | 约束 |
|---|---|
| 风格 | 简约舒适，水彩清新 |
| 色彩 | 浅色系，透明感 |
| 细节 | 水彩笔触轻松，边缘柔和 |

### 特殊场合

| 项目 | 约束 |
|---|---|
| 风格 | 按场景需求，保持水彩风格 |
| 色彩 | 按场景氛围调整 |
| 细节 | 水彩笔触适配场景 |

## 四、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须保持水彩绘画风格 |
| R2 | 必须基于角色基础形象 |
| R3 | 色彩必须体现透明叠色效果 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 3D渲染/写实摄影/数字绘画光滑感 |
| X2 | 高饱和荧光色/霓虹色 |
| X3 | 与角色基础形象严重不符 |
