# 场景基础形象生成 · 水彩风格

---

## 一、基础原则

1. **场景为本** — 造型由场景描述决定
2. **风格一致** — 水彩绘画，透明叠色
3. **氛围营造** — 水渍扩散，颜料流动
4. **色彩通透** — 低饱和，清新淡雅

---

## 二、提示词模板

```
{场景名称}，水彩绘画风格，透明叠色，水渍边缘，颜料扩散，纸张纹理，
{场景类型}，{室内/室外}，{季节+时间}，
{场景描述}，低饱和色彩，水彩笔触细腻，
{氛围关键词}，均匀柔光，
水彩风景，色彩层次丰富，自然晕染
图中不要有任何文字
```

---

## 三、约束规则

### 必守
| 编号 | 规则 |
|---|---|
| R1 | 必须为水彩绘画风格 |
| R2 | 必须声明「水渍边缘 + 颜料扩散 + 纸张纹理」 |
| R3 | 色彩必须体现透明叠色效果 |

### 严禁
| 编号 | 严禁 |
|---|---|
| X1 | 3D渲染/写实摄影 |
| X2 | 高饱和荧光色/霓虹色 |
| X3 | 复杂数字元素 |
