# 人物基础形象生成 · 水彩风格

---

## 一、基础形象原则

1. **面容即灵魂** — 五官是角色唯一锚点，水彩笔触精细渲染
2. **角色为本** — 基础着装由角色描述决定
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **清新淡雅** — 色彩透明叠加，水彩通透感

---

## 六、基础服装约束

> 基础服装由角色描述决定其最自然的常规着装，作为该角色「日常默认态」。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 学生/青春 | 校服/休闲装（清新色系） |
| 奇幻/童话 | 轻盈长裙/斗篷（淡雅色彩） |
| 日常/治愈 | 简约常服（低饱和色系） |
| 角色描述未明确 | 简约常服（按性别匹配） |

### 着装统一规则

- 服装风格须与水彩绘画美学一致（透明叠色、柔和边缘）
- 颜色低饱和，无复杂花纹/装饰
- 四视图服装款式完全一致

## 七、四视图设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 景别 | 要求 |
|---|---|---|---|---|
| 左一 | 人像特写 | 正面平视 | 头顶至锁骨 | 面部占60%+，五官清晰 |
| 左二 | 正视图 | 正面 0° | 全身立像 | 从头到脚完整展示 |
| 右二 | 侧视图 | 右侧 90° | 全身立像 | 纯侧面轮廓清晰 |
| 右一 | 后视图 | 后方 180° | 全身立像 | 后脑/背部清晰 |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面从左至右并排四视图 |
| 背景 | 纯净浅灰或水彩纸纹理 |
| 站姿 | 自然站立、双脚平行微分 |
| 全身展示 | 必须从头顶到脚底完整入画 |
| 特写展示 | 必须从头顶到锁骨完整入画 |
| 表情 | 中性微表情，符合角色气质 |
| 光线 | 均匀柔光，无硬阴影 |
| 一致性 | 四视图的肤色/体型/发型/面容/基础服装完全一致 |
| 画面比例 | 建议 4:1 或 3:1 |

## 九、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为水彩绘画风格 |
| R2 | 必须声明「水渍边缘 + 颜料扩散 + 纸张纹理」 |
| R3 | 色彩必须体现「透明叠色」效果 |
| R4 | 必须指定「四视图一致性」 |
| R5 | 全身立像必须从头顶到脚底完整展示 |
| R6 | 必须声明角色身高和头身比 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 3D渲染/写实摄影/数字绘画光滑感 |
| X2 | 高饱和荧光色/霓虹色 |
| X3 | 复杂场景背景（必须纯色或纸纹理） |
| X4 | 全身立像裁切头顶或脚底 |
| X5 | 忽略身高和头身比约束 |
