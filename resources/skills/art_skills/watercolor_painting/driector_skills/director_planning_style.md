# 叙事规划手法 · 水彩风格

---

## 一、风格定位

水彩风格适合以下叙事类型：
- 治愈系故事
- 青春成长
- 童话改编
- 温馨日常

## 二、叙事节奏

| 阶段 | 节奏 | 色彩建议 |
|---|---|---|
| 开篇 | 舒缓引入 | 浅色调，透明感强 |
| 发展 | 渐入佳境 | 色彩逐渐丰富 |
| 高潮 | 情感爆发 | 色彩浓度提高，但仍保持通透 |
| 结尾 | 余韵悠长 | 回归浅色调，留白感 |

## 三、视觉叙事技巧

1. **色彩情绪**：用色彩明暗变化暗示情绪变化
2. **水渍扩散**：用颜料扩散效果暗示情感流动
3. **留白处理**：适当留白营造呼吸感和想象空间
4. **笔触变化**：紧张场景笔触有力，温馨场景笔触柔和
