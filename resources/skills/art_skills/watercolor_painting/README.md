# 水彩绘画风格说明

本风格专为"水彩绘画"题材打造，所有美术提示词、规范和生成内容均严格遵循：

- **水彩艺术**：以传统水彩画为美学基础，强调色彩透明感、水渍边缘、纸张纹理
- **手绘质感**：保留画笔笔触、颜料流动、水分扩散的自然效果
- **清新淡雅**：色彩明快通透，适合治愈系、童话、青春成长等题材
- **艺术表现力**：画面具有手工绘画的温度感，区别于数字绘画的冰冷感

## 适用范围

- 水彩风格的AI美术生成（角色、场景、道具、分镜等）
- 需要手绘质感、清新淡雅氛围的视觉创作
- 童话、治愈系、青春题材的动画短片

## 严禁内容

- 3D渲染、写实摄影风格
- 高饱和荧光色、霓虹色
- 数字绘画的光滑平整感
- 暗示性、暴露等不适宜内容

## 风格体验

在本风格下，您将体验到：

- 角色形象清新自然，色彩透明叠加，具有水彩特有的通透感
- 场景具有水渍扩散、颜料流动的自然效果，纸张纹理可见
- 道具造型简洁明快，色彩层次丰富，边缘柔和
- 分镜与视频均以水彩绘画为基础，强调手绘温度与艺术表现力

---

本风格仅适用于"水彩绘画"相关项目。如需其他风格（如写实、3D、像素等），请勿使用本套提示词。
