# 《逆天布衣》AI剧本格式（专业版·完整版） - 全30集资产总表与场景视觉库

> **项目名称**：逆天布衣  
> **剧本类型**：AI视频生成专用剧本  
> **适用工具**：即梦 / 可灵 / Runway / 万兴剧厂  
> **版本**：专业版 v5.0（全30集资产完整版·角色补充·生物补充·55主场景视觉描述）  
> **总集数**：第1-30集  
> **每集时长**：约21分钟（7节×3分钟）  
> **生成日期**：2025年

---

## 一、格式规范

### 1.1 分镜编号规则
E{集数}-S{节数}-C{镜头号}  
示例：E01-S01-C01  
含义：第1集 第1节 第1号镜头

### 1.2 景别标注
| 标注 | 英文 | 含义 |
|------|------|------|
| 大远景 | Extreme Long Shot | 展现广阔环境，人物极小 |
| 远景 | Long Shot | 展现完整场景，人物全身 |
| 全景 | Full Shot | 人物全身，占画面1/2以上 |
| 中景 | Medium Shot | 人物半身，膝盖以上 |
| 近景 | Close Shot | 人物胸部以上 |
| 特写 | Close-Up | 人物面部或物体局部 |
| 大特写 | Extreme Close-Up | 眼睛、手指等极小局部 |

### 1.3 运镜标注
| 标注 | 含义 |
|------|------|
| 固定 | 机位不动 |
| 推 | 镜头向前推进 |
| 拉 | 镜头向后拉远 |
| 摇 | 机位不动，镜头左右/上下摇 |
| 移 | 机位平行移动 |
| 跟 | 镜头跟随人物移动 |
| 升 | 镜头向上移动 |
| 降 | 镜头向下移动 |
| 环绕 | 镜头围绕人物旋转 |
| 手持 | 模拟手持晃动感 |

### 1.4 特效标注
| 标注 | 含义 |
|------|------|
| 粒子 | 火星、灰尘、灵气等颗粒效果 |
| 光效 | 光柱、光晕、闪光等 |
| 烟雾 | 烟雾、雾气、蒸汽 |
| 火焰 | 炉火、火球、火焰 |
| 电光 | 闪电、电网、电火花 |
| 紫光 | 噬灵族/始祖相关紫色光芒 |
| 金光 | 炎帝诀/传承相关金色光芒 |
| 碎裂 | 镜面、墙壁、空间碎裂 |
| 扭曲 | 空间扭曲、空气波纹 |

### 1.5 时长标准
| 项目 | 标准 |
|------|------|
| 每集时长 | 约21分钟（7节×3分钟） |
| 每节时长 | 180秒 |
| 每镜头时长 | 6-8秒 |
| 每节镜头数 | 23-30个 |
| 对话镜头 | 每句台词独立镜头 |
| 动作镜头 | 每个动作独立镜头 |

### 1.6 台词标注规则
每个镜头必须包含：
- **台词/对白**：该镜头中角色说的具体内容
- **说话人**：明确标注是谁在说
- **语气提示**：括号内标注情绪和语气
